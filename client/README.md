# Grocery MERN Platform

A full-stack Grocery E-commerce Platform built using the MERN Stack.

## Features
- User Authentication
- Browse Grocery Products
- Add to Cart
- Order Management
- Admin/Seller Dashboard
- Product Categories
- Image Upload
- Responsive Design

## Tech Stack

### Frontend

- React.js
- Vite
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
 ### Installation

Clone Repository

git clone https://github.com/Samapti2004/my-grocery.git

### Backend Setup

cd backend
npm install
npm run dev

### Frontend Setup

cd client
npm install
npm run dev

### Environment Variables

Create ".env" files in frontend and backend.

Example backend ".env":

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key

Example frontend ".env":

VITE_BACKEND_URL=http://localhost:5000
